# Changelog

## v0.1.0-m1 — Milestone 1 Preview

### Included

- one four-case synthetic evidence-retrieval family;
- typed task contracts, tool manifests, replay decisions, oracle records, and results;
- deterministic declared-manifest compatibility evaluation;
- complete strict-outcome algebra and clause-level diagnostics;
- canonical JSONL plus a pure Markdown projection;
- checked-in JSON Schemas and representative golden artifacts;
- boundary, integrity, schema, semantics, and reproducibility tests;
- public architecture, evaluation, reproducibility, and limitations documentation.

### Interpretation boundary

This preview demonstrates mechanics on one synthetic family. It does not establish broader benchmark validity, production readiness, cross-domain behavior, runtime tool correctness, or general policy quality.
